# Bandit Spin 64

A 3D platformer that runs in the browser. You play a spinning orange bandicoot exploring a castle island in the style of Super Mario 64. It works on desktop and on phones with touch controls.

**Play:** https://kobotai.github.io/bandicorp/

## What's in the game

- 16 Power Stars across the castle grounds, the castle lobby and three painting worlds: Lava Keep, Frosty Peaks and Clockwork Spire.
- Two bosses: King Krab on the castle roof, and Baron Magmaw in the final battle. You beat Baron Magmaw by grabbing his tail, swinging him and throwing him into spiked bombs.
- Moves: spin attack, double and triple jump, and a body slam.
- Crates: fruit crates, TNT crates and iron bounce crates.
- Fruit makes your jumps higher as you collect it.

## Controls

| Action | Keyboard | Touch |
|---|---|---|
| Run | WASD / arrow keys | Drag on the left half of the screen |
| Jump (tap up to 3 times) | Space | JUMP |
| Spin / grab a tail | X or J | SPIN |
| Body slam (in the air) | Z or L | SLAM |
| Camera | Mouse drag, Q / E | Drag on the right half of the screen |
| Pause and star hints | Esc | ❚❚ |

Gamepads are supported too.

## Running it

The whole game is in `index.html`: the page, the styles and all the code. Models, textures, sound effects and music are all generated in code, so there are no asset files. The only external script is three.js r128, loaded from cdnjs.

Open `index.html` in a browser, or serve the folder with any static file server.

The characters, music and art are original. The game is a tribute to the genre and does not use any assets from Nintendo, Sony or Activision games.
